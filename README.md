# BACD 2027 Partnerships & Sponsorships

Static site for the BACD 2027 partnership and sponsorship opportunities.

| Path | What it is |
|---|---|
| `/` | Front page: choose The 2027 Portfolio or The Partner Guide |
| `/premium/` | The 2027 Portfolio (curated brochure, rate card, full details, glossary) |
| `/detailed/` | The Partner Guide (every opportunity with prices) |
| `/BACD_2027_Partnerships.pdf` | PDF version |

Each page is a single self-contained HTML file (fonts and images embedded), so no build step is needed.
Deploy on Vercel with Framework Preset "Other" and the default settings.
